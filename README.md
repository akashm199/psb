# PSB

Spring Boot JAR project for personal registration and company profile management.

Technology stack:
- Java 17
- Spring Boot 3
- Spring Security
- JWT
- MySQL
- JSP + HTML + CSS

This project is packaged as a JAR and can be run with:

mvn clean package
java -jar target/psb-0.0.1-SNAPSHOT.jar
